# EEET2256-Major-Project
Major Project for EEET2256 (Introduction to embedded systems) RMIT, 2018

This project focused on the implementation of a camera system capable of pan and tilt functionality through the use of two servo motors and a commercially available gesture sensor (Broadcom APDS-9960), on the ATMEGA32A micro-controller. Implementation took place in Embedded C and Assembler, these two methods were compared and contrasted with regard to speed, size of compiled code and functionality. The project scope covers the design of the system, sourcing of components and the development of all code by the author (no external libraries or the use of functions not built into the language or compiler). 
Many of particulars of this project were requiered by the assesment task.
